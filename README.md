One new English word, coined for make.fun's "Invent a Word We Need" bounty: **corridance** — the mirrored sidestep dance of two people trying to pass each other in a hallway. English has no word for that small daily moment, so this entry coins one: sayable, spellable, memorable, built from parts English already owns.

## Run it

```sh
python3 main.py /output/entry.txt
```

`main.py` reads the entry from `entry.txt` (the single source of truth), checks it is 1–140 characters, a single line shaped `word — definition`, and writes it to `/output/entry.txt`. Standard library only, no network, deterministic output.
